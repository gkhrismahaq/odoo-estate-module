## 1. Persiapan Struktur Modul
- [x] 1.1 Membuat file root `__init__.py` yang kosong/sesuai standar.
- [x] 1.2 Membuat file root `__manifest__.py`.

## 2. Definisi Manifest
- [x] 2.1 Mengisi `__manifest__.py` dengan dictionary informasi modul dasar (name, version, summary, description, author).
- [x] 2.2 Menambahkan list `depends` di `__manifest__.py` yang berisi: `['estate', 'website', 'payment', 'account']`.
- [x] 2.3 Mengatur kunci `application` bernilai `True` agar modul tampil di bagian utama daftar aplikasi Odoo.
