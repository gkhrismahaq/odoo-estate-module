# Odoo 17 Module Development

Repositori ini adalah proyek pengembangan modul kustom untuk **Odoo 17**, yang diatur agar mudah dijalankan menggunakan **Docker** Saat ini, proyek ini mencakup pengembangan modul: **Real Estate Management (`estate`)**: Modul kustom untuk mengelola properti real estate, termasuk bangunan, apartemen, dan penyewa.

---

## Tech Stack

- **Odoo 17.0**
- **PostgreSQL 15**
- **Docker & Docker Compose**
- **Makefile**
